AutoJob v1.5.1 (public source)

1. Install Node.js LTS and Google Chrome on Windows.
2. Run EDIT_PROFILE.bat to create local private profile.json and config.json.
3. Put your own resume.pdf in this folder (or edit resumePath).
4. Optionally install Simplify Copilot in the dedicated Chrome profile (SETUP_SIMPLIFY.bat).
5. Double-click START_ALL.bat. Sign into websites, then type READY.
6. Review VIEW_RESULTS.bat and REVIEW_BLOCKERS.bat after the run.

IMPORTANT: Source does not include applicant PII, a resume, logins, or browser sessions.
A clicked Submit button is NOT independent proof that an employer accepted an application.

See README.md for detailed setup and troubleshooting.
